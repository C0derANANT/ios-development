# iOS Development

Native iOS apps I am building while learning Swift and SwiftUI. Each folder is a
complete Xcode project with its own README, and can be opened and run on its own.

## Projects

| # | App | What it does | Built with |
| - | --- | ------------ | ---------- |
| 1 | [Pursuit](Pursuit/) | Job application tracker: log every application and follow it from wishlist to offer | SwiftUI, SwiftData |

## Running a project

1. Install Xcode 26 or later on a Mac.
2. Open the `.xcodeproj` file inside the project's folder.
3. Pick an iPhone simulator and press **Cmd + R**.

None of the projects need API keys or third-party packages unless their own README says so.
